Astelio IME の使い方

英語配列キーボードのための日本語入力。アニメーションで操作を紹介します。

はじめに日本語と英語入力と変換 候補の選び方予測ともしかして便利な機能 設定

1はじめに

インストールすると、キーボードの一覧に「Astelio IME」が入ります。

  1. すでに起動していたアプリは、起動し直すと使えるようになります（サインアウトして入り直すと確実です）。
  2. タスクバーの「あ / A」が Astelio IME の入力モードです。ほかの入力方式から切り替えるときは Win+Space。
  3. 一覧に出ないときは、［設定］→［時刻と言語］→［言語と地域］→［日本語］→［言語のオプション］→［キーボードの追加］で「Astelio IME」を選びます。

2日本語と英語の切り替え

右Alt を1回押して離すと日本語、左Alt を1回押して離すと英語になります。

  • Alt を単独で押しても、アプリのメニューは開きません。
  • 切り替えたときは、入力位置の近くに「あ」「A」が少し表示されます。
  • 入力モードはアプリの間で共有されます（メモ帳で日本語にすると、ブラウザーも日本語）。

3入力と変換

ローマ字で打つと、点線の下線の付いた「未確定の文字」になります。Space で変換、Enter で確定します。

  • Shift+英字は半角英字のまま未確定になり、かなと一緒に変換できます（iPhoneを買う）。
  • 変換中は ←→ で文節を移動、Shift+←→ で区切りを変えます。
  • Esc で変換前のかなに戻ります。確定の直後なら Ctrl+BackSpace で確定を取り消せます。

4候補の選び方

もう一度 Space を押すと候補の一覧が開きます。↓↑ で選び、数字キーでも選べます。

  • 候補が多いときは最大3列に広がります。←→ で列を移動します。
  • 右端の列は、読みに関連する絵文字です。最後の列から → で移って選べます。
  • 「あつい → 暑い / 熱い」のような語には、使い分けの説明を出す予定です。

5予測ともしかして

2文字ほど打つと、入力中から候補が出ます。Tab で選び、Enter で確定します。

  • 打ち間違えたときは「もしかして」として正しい語を出します（ゆーあー → ユーザー）。
  • 一度選んだ語は、次から先に出ます。候補の一覧で Ctrl+Delete を押すと、その履歴を消せます。

6便利な機能

  • 「きょう」「あした」を変換すると日付に（2026-09-27、2026/09/27、9/27 など）。
  • 文の頭で 1. と打つと「1. 」（箇条書きの番号）。
  • [ を打つと「」が入り、カーソルは括弧の中に。
  • 「えもじ」と打って Tab で絵文字の一覧。読みで探せます（いぬ → 🐶）。
  • F6〜F10 でひらがな・カタカナ・半角カナ・全角英数・半角英数。

7設定と困ったとき

タスクバーの「あ / A」を右クリックすると、次の設定ができます。

  • 入力モードの共有、数字の後のピリオド、括弧の自動補完、アプリごとに使わない設定
  • 入力の履歴（使う・一時停止・削除）、ユーザー辞書

パスワード欄では日本語入力にならず、履歴も残りません。入力した内容を外部に送ることはありません。
