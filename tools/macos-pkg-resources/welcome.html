Astelio をインストールします

ローマ字で打って Space で変換する日本語入力です。変換も履歴も、この Mac の中だけで動きます。

nihongo　→　にほんご　→　日本語

ローマ字で入力 → Space で変換 → Return で確定

① アプリを「/Library/Input Methods」に置きます

macOS は、このフォルダーにあるものだけを日本語入力（入力ソース）として扱います。そのため管理者のパスワードを聞かれます。

② 入力ソースとして登録します

インストールの最後に、ログイン中のユーザーに Astelio を登録します。

③ セットアップウィザードが開きます

キーボードへの追加と、左右の ⌘ での切り替えを、アニメーションと説明を見ながら設定します（2〜3 分）。
